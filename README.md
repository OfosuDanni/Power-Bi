# Credit Card Transaction Power BI Dashboard

## Project Overview

Created an interactive Power BI dashboard to analyze credit card transactions and customer spending.

### Dataset
- 50,000 transactions
- 50,000 unique customers
- Transaction, customer, merchant, category, and gender data

### Data Preparation
- Cleaned and reviewed the dataset
- Verified unique Customer IDs
- Changed Customer ID to Text
- Created a Gender Status field to identify complete and missing gender data
- Reviewed and standardized birthdate formats

### Key Metrics
- Total Customers: 50,000
- Total Transactions: 50,000
- Total Transaction Amount: $22.11M
- Average Transaction Amount: $442.10

### Power BI Analysis
- Transaction amount by category
- Top 10 merchants by transaction amount
- Transaction count by category
- Average transaction amount by category
- Transaction amount by gender
- Top 10 customers by transaction amount
- Spending by category and gender
- Gender data completeness

### Interactive Features
- Gender filter
- Category filter
- Merchant filter
- Synchronized slicers across report pages

- Power BI
- Power Query
